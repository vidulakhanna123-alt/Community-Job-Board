# Community jobs dashboard

1. Create a GitHub repo and upload everything in this folder (keep the folder structure).
2. Repo Settings > Pages > Deploy from branch > `main` / `/docs`.
3. Repo Settings > Actions > General > Workflow permissions > Read and write.
4. Actions tab > "Update jobs" > Run workflow. After that it runs daily at 8:00 AM IST.
5. Your dashboard is at https://<your-username>.github.io/<repo-name>/
6. Edit `config.yaml` to add companies, skills or Google Alert feeds (for SolarWinds, Higher Logic).

Application statuses are saved in your browser only, per device.
